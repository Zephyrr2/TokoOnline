# Toko Online 🛒 (Laravel Project)

Aplikasi e-commerce berbasis Laravel.

## 📌 Fitur  
- Framework Laravel  
- Manajemen produk & pengguna  
- Database menggunakan MySQL  

## 🚀 Cara Menjalankan  
1. Clone repo:  
   ```bash
   git clone https://github.com/Zephyrr2/TokoOnline.git
2. Install dependensi:
   ```bash
   composer install
3. Atur .env, jalankan migrasi:
   ```bash
   php artisan migrate
4. Jalankan aplikasi:
   ```bash
   php artisan serve
